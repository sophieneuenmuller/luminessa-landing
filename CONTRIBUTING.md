## English Version

This is a **personal project and portfolio**. As such, the repository is maintained solely by its owner (Sophie). While it is public for educational and professional demonstration purposes, **external code contributions are generally not accepted.**

### 🛠️ Professional Standards
I maintain this project with high standards of quality and consistency. These are the rules I follow:

1.  **Architecture:** Purely static (SSG). No client-side JS unless strictly necessary.
2.  **Naming:** `PascalCase.astro` for components, `kebab-case.astro` for pages.
3.  **Config:** All data must be imported from `src/site.config.ts`. No hardcoded data.
4.  **Commits:** I use [Conventional Commits](https://www.conventionalcommits.org/). No AI attribution is allowed in the history.
5.  **Styling:** Utility-first via Tailwind, sticking to the defined "Atelier" palette.

## Versión en Español

Este es un **proyecto personal y portfolio**. Por lo tanto, el repositorio es mantenido exclusivamente por su propietaria (Sophie). Aunque es público para fines educativos y demostración profesional, **generalmente no se aceptan contribuciones de código externas.**

### 🛠️ Estándares Profesionales
Mantengo este proyecto con altos estándares de calidad y consistencia. Estas son las reglas que sigo:

1.  **Arquitectura:** Puramente estática (SSG). Sin JS en el cliente a menos que sea estrictamente necesario.
2.  **Nomenclatura:** `PascalCase.astro` para componentes, `kebab-case.astro` para páginas.
3.  **Configuración:** Todos los datos deben importarse de `src/site.config.ts`. Sin datos hardcodeados.
4.  **Commits:** Uso [Conventional Commits](https://www.conventionalcommits.org/). No se permite la atribución de IA en el historial.
5.  **Estilos:** Utility-first mediante Tailwind, respetando la paleta de colores del "Atelier".
